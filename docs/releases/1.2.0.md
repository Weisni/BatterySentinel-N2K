# Orion Bridge 1.2.0

The first official firmware release for Orion Bridge on the Orion-R5 board with
the 4 MB ESP32-C3 SuperMini. It receives Victron Orion Bluetooth Instant Readout
and forwards input/output values to NMEA 2000.

## Included

- German/English HTTPS setup and live portal, channel aliases and NMEA instances.
- Administrator password changes and BOOT-confirmed recovery preserving settings.
- Authenticated phone-file OTA with hardware/version, size and image-integrity checks.
- Per-channel voltage extrema/trends and covered charge/energy observations.
- Configurable voltage, missing-data and charger-error notifications, qualification,
  recovery, acknowledgement and optional reminders. Notifications default off.
- Validated network UTC, uptime fallback and incident/communication diagnostics.
- German operating/installation manual with a device-specific Wi-Fi QR handover
  workflow; installer provisioning is required for the individual access label.

## Installation

For an existing Orion Bridge, save `orion-dongle-1.2.0.bin` on your phone and
upload it under **Settings → Firmware update** while power remains stable.
Saved administrator, Wi-Fi, Orion and NMEA settings are retained. Observations,
incidents and the current boot's clock correlation restart after reboot.

The separate `orion-dongle-1.2.0-usb.zip` contains segmented USB images and a
flash layout that leaves the NVS settings partition untouched. Use SERVICE
before USB and follow its README; never upload the ZIP as an OTA image.

Verify downloads using `SHA256SUMS.txt`. `release-manifest.json` records the exact
source commit, CI run, application target/version and each asset's digest.

## Validation and current limits

The publication workflow requires the complete native, firmware, HTTP, portal,
OTA, OLED/TWAI fixture and simulator checks at the tagged source commit. It
downloads and verifies the uploaded draft assets before publishing.

Standard Wi-Fi settings are retained. The builder accepts the observed Wi-Fi
heating and slow cooling; the reduced-power experiment is discarded. No calibrated
chip temperature or closed-case thermal qualification is claimed.

Observations concern the Orion channels, not complete battery SOC or remaining
runtime. Optional NMEA alert delivery is experimental and defaults off; display,
sound and withdrawal must be checked on the actual receiver. Hardware power,
isolation, installation-site RF, enclosure and boat/Garmin acceptance remain
device-specific checks in the manual. This software release is not certification.
