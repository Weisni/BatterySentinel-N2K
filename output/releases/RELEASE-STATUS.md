# Project-internal hardware export archive

This directory contains historical engineering ZIP exports and verification
records for the unbuilt R4 WROOM design. These files are not user downloads,
manufacturing instructions for the actual device, or evidence of an existing or
previously released hardware product. Do not order or assemble these archives.
The ZIP files, checksum list and verification record remain unchanged.
