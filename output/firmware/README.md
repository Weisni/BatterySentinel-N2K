# Orion Bridge firmware download

Use [Orion Bridge 1.2.0](1.2.0/README.md) for the ESP32-C3 SuperMini on the
Orion-R5 board. Its download page contains the application image and checksum.
Follow the [installation instructions](../../docs/firmware-update.md).

The current download includes observations, configurable notifications and a
network-synchronized event clock. Review notification settings after installation.
