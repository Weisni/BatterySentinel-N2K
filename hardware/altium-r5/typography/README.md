# Native Altium-Beschriftungsprobe

`R5-Beschriftungsprobe.PcbDoc` ist eine separat in Altium Designer 26.10.1 geöffnete und im nativen Binary-6.0-Format gespeicherte Schrift-/Logoprobe. Sie enthält fünf echte TrueType-Textobjekte in Arial Rounded MT Bold und drei gefüllte Regionen für das eigene Logo. Die Texte sind in Altium bearbeitbar. Die Datei enthält keine elektrischen Bauteile oder Leiterbahnen und ist kein R5-Fertigungsstand.

Geprüft wurden die sichtbaren runden Buchstaben, Groß-/Kleinschreibung, eine um 90° gedrehte Beschriftung und eine gespiegelte Unterseitenbeschriftung. Die Windows-Schriftdatei wird nicht als separate TTF mitgeliefert; Altium hat beim nativen Speichern seine üblichen Schrift-/Konturdaten im Dokument hinterlegt. Die gespeicherten Altium-Konturen und die Exportanbindung werden in [den Branding-Unterlagen](../../../assets/branding/README.md) dokumentiert. Der [native Vergleich](../../../assets/branding/native-typography-verification.json) bestätigt alle fünf Textobjekte und einen Gerber-Readback beider Seiten ohne Flächenabweichung.

SHA-256 des nativ gespeicherten Dokuments: `d0f616a14110336d29a8a5000907c22a0a3a1d85d4c010bf6f894305e9ddadcc`.
